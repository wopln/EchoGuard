# Troubleshooting

**Windows and Discord inputs differ:** allowed. EchoGuard confirms verified active recording sessions rather than assuming Windows defaults. Change Discord yourself if intended.

**Physical input selected while Discord uses Sonar:** these are different capture endpoints. Select the actual processed voice endpoint to choose Detect Echo the known fix. Upstream physical-to-Sonar routing cannot safely be inferred.

**Suggested or Unknown:** join voice and choose Detect Echo. Suggested defaults are estimates, not permission to apply exclusion.

**Duplicate microphone names:** compare the identity suffix and full ID under Settings > Available microphones. Selection uses identity, not label.

**Disconnected or recreated device:** reconnect it. Exact ID or a unique strict hardware/driver/role/container match can recover it. Otherwise select manually. If the same ID reports different properties, choose Auto Detect then reselect after review. Disabled devices stay disabled.

**Other virtual mixer/webcam/USB input:** discovery and selection are supported; a generic echo exclusion is not. Only the known positively identified Sonar/Discord extra playback path is protected.

**AudioInitialization active:** exclusions are blocked to avoid overlap. Selection/discovery still work. Preserve the helper's personal features and avoid interrupting important calls to test an indicator.

**Fix Echo unavailable:** selected/observed input, unique Sonar pair, verified Sonar writer and matching Discord share session must all be present, without another active Discord recording endpoint. Trust errors and incomplete inventories also block changes.

**Active indicator but echo audible:** native target mute was confirmed; sound was not analyzed. Test from another device with headphones and avoid same-PC stream playback. Review other acoustic/monitoring paths. Disable protection if voice/game behavior differs.

**Remember off:** in-memory selection can continue, but identity/history and future protection consent are not saved. Startup remains independent. Hashed rollback records remain until safe restoration.

**Restore needs attention:** preserve the local recovery journal, reconnect devices and reopen. Uninstall refuses unresolved restoration intentionally.

**Advanced controls moved:** use the gear for confidence, identity details, Remember, diagnostics, report export and restoration. Exit completely is in Settings and the tray menu. Close hides to tray; Minimize uses the taskbar. Need Help is offline.

**Not checked yet:** this is the initial main-screen workflow, not a claim about the background inventory. Request Detect Echo. Fix Echo remains disabled until a supported path is confirmed. Active/armed saved protection still reports its real backend state.


## Window sizing (0.2.2)
Drag empty header space; double-click to maximize/restore. The six-DIP borders resize, with the rounded-corner target slightly inset. Minimize uses the taskbar; Close hides to tray. Opening again restores the previous state. Minimum is normally 850 x 670 DIPs. Shorter monitor work areas use vertical scrolling instead of scaling the page. Windows Snap is handled by the OS; no fixed aspect ratio is enforced. Other-monitor DPI/scaling acceptance should be checked on that hardware.
